# NS-3 Sensor Farm Simulation

This repository contains a project focused on simulating reliable large-data transmission over LoRa in an NS-3-based sensor farm scenario.

## Project Goal

Design and evaluate a custom reliability protocol that improves large payload delivery by using:

- Data chunking
- Acknowledgments
- Selective retransmission

## Repository Status

At the moment, this repository is a lightweight project stub and mainly documents the simulation objective.
