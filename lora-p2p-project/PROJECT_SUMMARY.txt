================================================================================
🎯 WHAT IT DOES
================================================================================

Simulates LoRa radio P2P image transfer with:
• Chunked transmission (92-byte LoRa-sized chunks)
• Automatic ACK mechanism
• Smart retransmission on packet loss
• Performance metrics & analysis
• Configurable packet loss simulation

Use cases:
• Protocol performance testing
• Reliability analysis
• Packet loss impact studies
• LoRa communication research

================================================================================
🔬 TEST SCENARIOS INCLUDED
================================================================================

1. 1KB_NoLoss    - Baseline small (0% loss)
2. 5KB_NoLoss    - Baseline medium (0% loss)
3. 10KB_NoLoss   - Baseline large (0% loss)
4. 5KB_10Loss    - Light packet loss (10%)
5. 5KB_20Loss    - Moderate packet loss (20%)
6. 5KB_30Loss    - Heavy packet loss (30%)
7. 10KB_20Loss   - Large image + loss (20%)

================================================================================
📈 TYPICAL PERFORMANCE
================================================================================

Perfect Conditions (0% loss):
  5KB → ~30s, 0% retransmissions, 100% efficiency

Realistic Conditions (20% loss):
  5KB → ~60s, 25-35% retransmissions, 75% efficiency

Challenging Conditions (30% loss):
  5KB → ~90s, 45-60% retransmissions, 60% efficiency
